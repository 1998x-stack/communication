# 客户与商务：教学与教练参考

> 本文是本项目归纳的训练设计，不表示原研究机构认证这些具体参考话术。

## 教学目标
明确真正采购动机、真实承诺边界和双方确认的交付标准。

## 沟通核心动作
1. **识别需求**
2. **建立可信度**
3. **管理预期**

## 沟通流程
1. 先问具体使用场景、成功标准、最优先顾虑和决策人。
2. 以证据区别已验证能力、可能方案和尚不确定的信息。
3. 确认范围、时间、成本、验收标准与变更流程，书面复述。

## 对方反问时，如何回应
- “别人更便宜”：先比较范围、支持和总体成本。
- “先做再补合同”：解释可逆准备和正式开工的边界。
- “现在就保证”：不承诺无法验证的日期和功能。

## 安全与伦理底线
不欺瞒客户、不伪造验收、不泄露第三方商业信息，不绕开隐私合规要求。

## 课堂练习组织
- 先读背景和开场，学习者用 20–40 秒尝试自然回应。
- 后续依照案例的 `roundCount` 逐轮播放对方追问，每轮都等待学习者回应；一轮题不添加额外问题。
- 随轮次推进具体的质疑、新约束和边界，而不是使用固定的“第三轮模板”。
- 结束（复盘）：四维自评，每维 0–25 分；着重分析具体句子，不夸大“口才训练”效果。
- 改写（迁移）：同一情境先分别用温和、坚定、简洁三种语气表达，内容保持真实。

## 在仓库中读取案例
- 单题内容源：`data/entries/clients/<case-id>.json`
- 结构化卡片：`data/cases/clients.json`
- 当前题量：30；难度、标签、轮次由每题元数据独立指定，不能由 ID 推断
- 数据格式和新增流程：`data/README.md`

## 理论延伸
澄清式提问 / 期望管理。参考：https://www.pon.harvard.edu/daily/negotiation-skills-daily/principled-negotiation-focus-interests-create-value/

研究框架需要适应具体关系、文化和安全条件。不要把“让对方同意”当作训练唯一成功标准。
