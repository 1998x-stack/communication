# 公众表达与临场发言：教学与教练参考

> 本文是本项目归纳的训练设计，不表示原研究机构认证这些具体参考话术。

## 教学目标
让公众表达观点清晰、证据可核实，并在被追问时保持沉着。

## 三大支柱
1. **听众导向**
2. **结构表达**
3. **问答收束**

## 沟通流程
1. 先说明这次表达对听众的意义及一句话核心观点。
2. 用一个有根据的事实或例子支撑观点，同时说明局限。
3. 回应现场问题，承认未知并给出可靠的后续信息或行动。

## 对方反问时，如何回应
- “你说的证据是什么？”：具体说明来源与适用范围。
- “能举个例子吗？”：提供贴近听众任务的可理解示例。
- “现在答不出怎么办？”：坦诚说明待核实事项，约定补充方式。

## 安全与伦理底线
不要在演讲或答疑中编造统计数据、夸大风险或用羞辱阻止听众追问。

## 课堂练习组织
- 第一轮（观察）：读背景与开场，学习者先在 20–40 秒内给出自己的回应。
- 第二轮（追问）：教练用第一轮反问测试共情和逻辑结构。
- 第三轮（升级）：教练加入额外压力、目标冲突或边界问题，引导学习者形成行动。
- 结束（复盘）：四维自评，每维 0–25 分；着重分析具体句子，不夸大“口才训练”效果。
- 改写（迁移）：同一情境先分别用温和、坚定、简洁三种语气表达，内容保持真实。

## 在仓库中读取案例
- 单题内容源：`data/entries/public-speaking/<case-id>.json`
- 结构化卡片：`data/cases/public-speaking.json`
- 当前题量：1；难度、标签、轮次由每题元数据独立指定，不能由 ID 推断
- 数据格式和新增流程：`data/README.md`

## 理论延伸
核心信息 / 支撑事实 / 临场问答。参考：https://www.toastmasters.org/

研究框架需要适应具体关系、文化和安全条件。不要把“让对方同意”当作训练唯一成功标准。
