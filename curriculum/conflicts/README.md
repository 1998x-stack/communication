# 争执与利益冲突 · 课程与增量资料

**三大核心：** 控制升级 → 寻找真实利益 → 建立可执行方案。

**教学目标：** 降温、识别利益、制定可执行协议并守住安全。

**参考方法：** Principled Negotiation / BATNA

## 训练步骤
1. 读背景和已知事实，理解对话对象的约束与真实顾虑。
2. 用三大核心组织自己的第一轮发言，不提前看示范。
3. 接受两次追问，争取用更少的字、更清楚的事实推进事情。
4. 四维自评并重试一次：结构、理解、尊重与行动。

## 本类课程难度
- 低难度：第001–010题，主要训练清晰表达。
- 中难度：第011–020题，主要训练异议处理和边界。
- 高难度：第021–030题，主要训练复杂压力、利益冲突及安全判断。
