# 案例与扩展规范

源数据在 `data/seeds/{category}.txt`，每行以 `|` 分隔 7 列：标题、背景、对方开场、首次反问、再次追问、期望行动、已知事实。避免在字段内部使用竖线。生成后的规范训练卡位于 `data/cases/*.json`，由 `npm run generate` 输出，页面读取 `data/catalog.json` 自动注册类别与案例。

初始 9 个场景，每类 30 例：1–10 基础、11–20 进阶、21–30 高压，总计 270 例 / 每例 6 个对话轮次和 3 个训练步骤。

## 新增案例

1. 在对应 `data/seeds/*.txt` **追加**一行 7 列；不要修改已发布案例的 ID 顺序，也不要在中间插入或删除行（会改变已有序号与进度）。
2. `npm run build` 重新生成并校验；生成器自动更新各类数量和总数。
3. 如果需要更加自由的教学脚本，可在 `data/overrides/{case-id}.json` 中提供局部覆盖（预留扩展目录）；现版本尚未实现覆盖读取，切勿把它误认为已经支持。
4. 通过 PR 审核敏感信息、清晰度、尊重与安全优先原则。

## 设计原则

学习者的答案不要求与示范逐字一致；示范用来观察结构、提问和对抗压力下的响应。不得收录可识别的真实个人、公司机密或未经授权对话。涉及危机的练习以现实安全支持优先，不提供危险关系中强行和解的建议。

## 未来演进

后续可以增加 schemaVersion 2，支持场景自定义分支树、人工点评、多种参考话术与 ChatGPT 导入；迁移时保持稳定 `id`，使用版本化转换而不是直接破坏旧条目。
