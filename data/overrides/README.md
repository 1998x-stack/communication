# 人工精修覆盖层

规范说明见 [案例数据协议](../README.md)。每个已有案例可以增加一个与 ID 同名的 JSON 文件，至少包含 `id` 与三轮 `responses`；可选 `steps`（三段具体训练要领）、`focus`（复盘教学重点）。

覆盖文件由 `scripts/generate.mjs` 在种子生成后合并，不会改变案例身份、难度、事实、角色顺序或题目数量。缺失案例、未知字段、过短答案会阻断构建，防止静默丢失。

目前提供 27 份精修样本（九类每类基础/进阶/高压各一例），其余案例仍是种子和通用教学模板生成的初稿。课程后续的增量精修，优先为每条追问写出有事实依据、自然口语、可执行后续动作的独立回应。
