# 270 道案例精修记录与验收标准

更新：2026-11-10。范围：九大场景、各30题，合计270题。原有27题保持独立精修，其余243题增补独立的三轮话术和`focus`，合计810段参考回应；每类基础、进阶、高压各10题。

## 精修目标

精修不是让参考答案变长，而是确保**事实支撑、真实反问、递进压力、明确落点**。每一题按原种子定义的情境与三次对方台词编写，不把“我理解你”换着说三遍：

1. 第一轮回答对方当下的问题，按场景选择结论、情绪理解、澄清或安全判断，不能擅自创造新事实；
2. 第二轮正面处理对方真正提出的质疑、误会、资源或关系压力；如不确定要标明待核实；
3. 第三轮回应更高约束，提出责任、时间、决策请求、选择、边界或安全退出条件；不承诺自己无法控制的结果。
4. 语句应能被普通人在现实中自然说出口，不鼓励背诵，不让“对方照做”成为唯一成功标准。
5. 自伤、威胁、暴力、未成年人安全和明显权力滥用等高风险场景以现实安全支持为优先目标，不强迫继续谈判。

## 构建契约

- `data/seeds/*.txt` 储存背景、开场、两次反问、行动目标和已知事实；原编号、分类、难度保持不变。
- `data/overrides/<case-id>.json` 为长期维护的独立精修来源，包含三段 `responses` 和 `focus`；生成器合并进 `data/cases/*.json`。
- `npm run build && npm test` 验证初始270题的覆盖层是否完整，三轮序列、同轮反问、回答重复、最短内容量、精修源与输出一致性，以及高风险实例是否具有安全优先回应。
- 新增案例可以按既有增量流程先成为草稿，再通过精修覆盖层升级为审校版；未精修的新题不会被误标成这批已经完成的270题。

## 仍待验证

“独立精修”仅表示本仓库的内容编辑过程完成，不代表通过临床、法律或正式职业教练认证。自动化校验也不能判定全部情绪细节、文化差异、叙述真实性或真实说话节奏。未来可通过课程教师、真实用户模拟演练和内容评审持续调整话术，尤其是高风险案例。
