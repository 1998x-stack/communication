# 沟通知识库分类契约

一级分类与二级主题唯一来源是 `content/categories.json`，文章清单唯一来源是 `content/posts.json`。每篇文章只有一个主 category/topic；跨领域关联使用 tags、reading_paths 与 related_cases。

| 一级领域 | 主要范围 |
|---|---|
| foundations | 通用沟通闭环、倾听、表达训练与复盘 |
| workplace | 向上汇报、同事协作、管理反馈 |
| family | 伴侣、代际边界、亲子沟通 |
| social-business | 朋友关系、客户需求与预期 |
| conflict-public | 利益协商、公众表达与临场问答 |

主题 slug 是公开 URL 与导航锚点的一部分，发布后保持稳定。新场景优先新增二级 topic；只有当主题形成稳定内容群时才评估新一级领域。
